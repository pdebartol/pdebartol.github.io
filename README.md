# Food Recommendations Website

A modern, elegant website showcasing curated food recommendations with an interactive interface.

## Features

- 🍽️ Curated food recommendations with ratings
- 📸 Image carousel for restaurant photos
- ⭐ Star rating system
- 📱 Responsive design
- 🎨 Modern, elegant UI with smooth animations
- 📝 Admin guide for content management

## Live Demo

[View the live site](https://your-username.github.io/food_rec/)

## Local Development

Simply open `index.html` in your web browser, or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

Then navigate to `http://localhost:8000`

## Content Management

See [ADMIN_GUIDE.md](ADMIN_GUIDE.md) for instructions on how to:
- Add new restaurants
- Update ratings
- Manage images
- Organize by categories

## Deployment

This site is deployed on GitHub Pages. See the deployment section below for setup instructions.

### GitHub Pages Deployment

1. Push your code to GitHub
2. Go to Settings > Pages
3. Select "Deploy from a branch"
4. Choose `main` branch and `/ (root)` folder
5. Save and wait for deployment
